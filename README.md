# 모챙이 🎨 — AI 이모티콘 메이커

0챙이 에이전트 시리즈(다챙이·가챙이·투챙이…)를 잇는, **이모티콘을 함께 만들어주는** 웹 에이전트입니다.
주제·컨셉을 같이 기획하고, AI가 **카카오 이모티콘 초안을 실제로 그려주고 다듬어줍니다.**

서버 없이 브라우저에서 바로 돌아가는 정적 웹앱입니다. (HTML/CSS/Vanilla JS)

## 핵심 기능

1. **🧠 컨셉 기획** — 주제(동물/사물/사람/음식 등) × 톤(병맛/귀여움/진지/시니컬/힐링 등)을 고르면, AI가 캐릭터·세계관·비주얼·제목 후보까지 담은 **컨셉안 여러 개**를 제안합니다.
2. **🖼️ 레퍼런스 아이디에이션 (표절 방지)** — 좋아하는 이모티콘을 **캡쳐해 올리면**, 스타일의 *추상적 특징만*(선 굵기·색감·비율·유머 코드·구도) 분석하고, **캐릭터·디자인은 베끼지 않는** 완전히 새로운 컨셉으로 변형 제안합니다.
   - ⚠️ 업로드한 이미지는 **글 분석에만** 쓰이고, 이미지 생성에는 직접 넣지 않습니다. 그림은 당신의 새 컨셉으로 새로 그립니다.
3. **✨ 이모티콘 작업실** — 컨셉을 기준으로 **실제 이모티콘 이미지를 생성**(Nano Banana)하고, 마음에 안 들면 **자연어로 다듬습니다**("배경 투명하게", "더 웃기게", "라인 굵게"). **기준 캐릭터**를 지정하면 세트 전체가 같은 캐릭터로 일관되게 나옵니다.
4. **📦 보관함** — 완성한 세트를 모아 PNG로 내려받습니다.

## 카카오톡 이모티콘 "불러오기"에 대해

카카오톡에서 **내가 구매한 이모티콘을 외부 앱으로 불러오는 공개 API는 없습니다.** (카카오 개발자 API는 사용자관리/푸시/분석용)
그래서 모챙이는 좋아하는 이모티콘을 **캡쳐해서 올리는** 방식으로 아이디에이션합니다. 이게 가장 현실적이고 안전한(저작권) 방법입니다.

## 시작하기

1. [Google AI Studio](https://aistudio.google.com/)에서 **Gemini API 키**를 발급받습니다. (무료, 단 이미지 생성은 유료 등급/크레딧이 필요할 수 있음)
2. `index.html`을 브라우저로 엽니다. (로컬 서버 권장 — 아래)
3. **⚙️ Gemini API 키 설정**에 키를 붙여넣고 저장 → **▶️ 시작하기**.

### 로컬 서버로 실행 (권장)

`file://`로 열어도 대부분 동작하지만, 로컬 서버로 여는 걸 권장합니다.

```bash
# Python
python -m http.server 5500
# 또는 Node
npx serve .
```

브라우저에서 `http://localhost:5500` 접속.

## 설정

- **이미지 모델**: 기본 `gemini-3-pro-image`(Nano Banana Pro · 품질·한글 텍스트 최강). 비용을 아끼려면 `gemini-2.5-flash-image`로 변경.
- **텍스트 모델**: 컨셉 기획·아이디에이션용. 기본 `gemini-2.5-flash`.
- **이미지 비율**: 카카오 이모티콘은 정사각(`1:1`) 권장.
- 키·작업물은 **이 브라우저에만** 저장됩니다 (설정·프로젝트 메타 = localStorage, 이미지 = IndexedDB).

## 카카오 이모티콘 규격 (참고 기본값)

| 유형 | 종수 | 사이즈 |
|---|---|---|
| 멈춰있는 이모티콘 | 32종 | 360×360px PNG(투명) |
| 움직이는 이모티콘 | 24종 | 360×360px |
| 큰 이모티콘 | 16종 | 540×540px |

> ⚠️ 위 수치는 **참고 기본값**입니다. 실제 제출 규격(종수·해상도·용량·파일형식)은 수시로 바뀌니, 제출 전 **[카카오 이모티콘 스튜디오](https://emoticonstudio.kakao.com/)**에서 최신 가이드를 반드시 확인하세요. 제출 자체도 스튜디오에서 직접 합니다.

## 파일 구조

```
mochangi-Agent/
├─ index.html          # 앱 셸 (시작 화면 · 사이드바 · 4개 뷰 · 모달)
├─ style.css           # 0챙이 시리즈 다크 테마 + 이모티콘 컴포넌트
├─ js/
│  ├─ gemini.js        # 텍스트 생성: 컨셉 기획 · 레퍼런스 아이디에이션 · 세트 구성
│  ├─ image.js         # Nano Banana 이미지 생성/편집(다듬기)
│  ├─ store.js         # IndexedDB(이미지) + localStorage(프로젝트)
│  ├─ config_modal.js  # API 키/모델 설정
│  ├─ config.example.js# 설정 예시(선택)
│  └─ main.js          # 컨트롤러(라우팅·전체 와이어링)
└─ README.md
```

## 저작권·표절 안내

- 올린 레퍼런스는 분석에만 쓰고 그림에 직접 넣지 않습니다.
- 그래도 특정 캐릭터·브랜드를 똑같이 만들지 않도록 **최종 확인 책임은 창작자에게** 있습니다.
- 생성 이미지에는 Google의 SynthID 워터마크가 포함될 수 있습니다.
